При написании библиотеки используется Row-major метод для укладки 2D матриц в 1D память компьютера. **Суть метода:** данные укладываются построчно: сначала первая строка, затем вторая и т.д.

Например, матрица

```text
10 20 30
40 50 60
```

хранится как последовательность `10, 20, 30, 40, 50, 60`.

Чтобы получить нужный элемент, используется формула индекса. Она зависит от значения `base_numeric`, которое задаётся при создании матрицы или меняется методом `set_base_numeric`.

Если вызвать `set_base_numeric(0)`, нумерация строк и столбцов начинается с нуля. Формула индекса:

**`index = r * cols + c`**,

где `r` — номер строки, `c` — номер столбца, `cols` — общее количество столбцов.

Если вызвать `set_base_numeric(1)`, нумерация начинается с единицы. Формула индекса:

**`index = (r - 1) * cols + (c - 1)`**,

где `r` и `c` — номера строки и столбца, переданные в `operator()`.

В общем случае для начального индекса `base_numeric` формула имеет вид:

**`index = (r - base_numeric) * cols + (c - base_numeric)`**.

Изменение `base_numeric` меняет нумерацию при обращении, но порядок хранения элементов остаётся прежним.

Подробное описание класса и всех доступных операций находится в [справочнике API](API_REFERENCE.md).
