## Подключение и требования

ZiMatLib — header-only библиотека на C++17. Отдельная сборка самой библиотеки не требуется. Подключите каталог `include` и зонтичный заголовок:

```cpp
#include <zimat/zimat.hpp>
```

При подключении репозитория через CMake:

```cmake
add_subdirectory(path/to/ZiMatLib)
target_link_libraries(my_app PRIVATE zimat)
```

Цель `zimat` имеет тип `INTERFACE` и передаёт пути к заголовкам и требование C++17.

## Быстрый старт

```cpp
#include <zimat/zimat.hpp>
#include <iostream>

int main() {
    zimat::matrix<int> a(2, 2);
    a(1, 1) = 1;
    a(1, 2) = 2;
    a(2, 1) = 3;
    a(2, 2) = 4;

    auto transposed = a.transpose();
    auto doubled = a * 2;
    auto cleared = a;
    cleared.fill(0);

    std::cout << transposed(1, 2) << '\n'; // 3
    std::cout << doubled(2, 2) << '\n';   // 8
    std::cout << cleared(1, 1) << '\n';   // 0
}
```

По умолчанию строки и столбцы адресуются индексами от `1`. Для индексации от `0` передайте `0` третьим аргументом конструктора.

## Класс `zimat::matrix`

```cpp
template<typename T, typename T1 = int>
class zimat::matrix;
```

`T` задаёт тип элементов. `T1` задаёт тип количества строк, столбцов и индексов. Для арифметических операций тип элементов должен поддерживать используемые операции (`+`, `-`, `*`, `/`) и присваивание результата.

[↑ К оглавлению](#навигация)

### Создание матрицы

#### Пустая матрица

```cpp
zimat::matrix<double> empty;
```

Создаётся матрица размером `0 × 0` с базовым индексом `1`.

#### Матрица заданного размера

```cpp
zimat::matrix<double> values(3, 4);
zimat::matrix<int> zero_based(2, 2, 0);
```

Первые два аргумента — число строк и столбцов. Третий аргумент — начальный индекс для строк и столбцов; по умолчанию он равен `1`. Элементы инициализируются значениями по умолчанию для `T` (например, нулями для числовых типов).

Размер должен быть неотрицательным, а произведение размеров должно помещаться в используемый тип. Текущий конструктор отдельно эти условия не проверяет.

[↑ К оглавлению](#навигация)

### Индексация и доступ к элементам

```cpp
matrix(row, column)
```

Оператор возвращает ссылку на элемент и позволяет его читать и изменять. Для константной матрицы возвращается константная ссылка:

```cpp
zimat::matrix<int> a(2, 2);
a(1, 2) = 7;
int value = a(1, 2);

const auto& read_only = a;
int same_value = read_only(1, 2);
```

При базовом индексе `1` допустимые индексы для матрицы `2 × 2` — строки и столбцы `1` и `2`; при базовом индексе `0` — `0` и `1`. Проверки индекса и выхода за границы в текущей реализации нет. Неверный индекс может привести к неопределённому поведению.

[↑ К оглавлению](#навигация)

### Изменение размера и заполнение

#### `resize(rows, cols, base_numeric = 1)`

Изменяет размер матрицы и задаёт её базовый индекс:

```cpp
a.resize(3, 4);       // размер 3 × 4, базовый индекс снова 1
a.resize(2, 2, 0);    // размер 2 × 2, индексы от 0
```

Данные сохраняются в пределах нового размера по правилам `std::vector::resize`: сохранённая часть остаётся на месте, новые элементы получают значение по умолчанию, лишние элементы удаляются. Аргумент `base_numeric` по умолчанию равен `1`, поэтому вызов `resize(rows, cols)` сбрасывает базовый индекс на `1`.

#### `fill(value)`

Заполняет все существующие элементы одним значением и возвращает ссылку на текущую матрицу (`matrix&`):

```cpp
a.fill(0);
a.fill(1).fill(2); // цепочка вызовов допустима; итоговое заполнение — значением 2
```

Метод не меняет размеры и базовый индекс. Для пустой матрицы вызов ничего не меняет.

[↑ К оглавлению](#навигация)

### Получение размеров и данных

Оба варианта геттеров размеров возвращают число строк или столбцов типа `T1`:

```cpp
auto row_count = a.rows();
auto column_count = a.cols();

// Эквивалентные имена:
auto same_row_count = a.get_rows();
auto same_column_count = a.get_cols();
```

`data()` и `get_data()` возвращают константную ссылку на внутренний `std::vector<T>`:

```cpp
const std::vector<int>& elements = a.data();
```

Элементы расположены в row-major порядке: сначала все столбцы первой строки, затем второй и так далее. Через эти геттеры изменить вектор нельзя.

[↑ К оглавлению](#навигация)

### Базовый индекс

`base_numeric()` и `get_base_numeric()` возвращают текущий начальный индекс типа `T1`. `set_base_numeric(value)` меняет его:

```cpp
a.set_base_numeric(0);
auto first_index = a.base_numeric();
```

Изменяется только то, какие индексы принимаются как начало при доступе через `operator()`. Данные и размеры матрицы не меняются. Старый способ адресации после смены базы использовать не следует.

## Арифметические операции

Операторы создают новую матрицу и не изменяют исходные матрицы.

| Операция | Смысл | Требуемые размеры |
|---|---|---|
| `a + b` | Поэлементное сложение | Одинаковое число строк и столбцов |
| `a - b` | Поэлементное вычитание | Одинаковое число строк и столбцов |
| `a * b` | Матричное умножение | `a.cols() == b.rows()` |
| `a * scalar` | Умножение каждого элемента на скаляр | Скаляр типа `T` |
| `a / scalar` | Деление каждого элемента на скаляр | Скаляр типа `T` |

Пример:

```cpp
auto sum = a + b;
auto difference = a - b;
auto product = a * b;
auto scaled = a * 2;
auto halved = a / 2;
```

Результат сохраняет размеры левого операнда (для матричного умножения число столбцов берётся у правого) и его базовый индекс. В текущей реализации проверки требований к размерам написаны, но не выполняют действие при ошибке. Поэтому нельзя полагаться на исключение или корректный результат при несовместимых размерах: сложение и вычитание могут выйти за границы данных, а умножение может вернуть некорректный результат.

Деление на ноль не проверяется. Для целочисленного `T` действует обычное целочисленное деление C++; например, `5 / 2` даёт `2`.

## Транспонирование

`t()` и `transpose()` возвращают новую матрицу, в которой строки и столбцы поменяны местами. `transpose()` вызывает `t()` и является более описательным именем.

```cpp
zimat::matrix<int> a(2, 3);
a(1, 1) = 1; a(1, 2) = 2; a(1, 3) = 3;
a(2, 1) = 4; a(2, 2) = 5; a(2, 3) = 6;

auto b = a.transpose(); // размер 3 × 2
// b:
// 1 4
// 2 5
// 3 6
```

Базовый индекс результата совпадает с базовым индексом исходной матрицы.

## Определитель

`det()` возвращает значение типа `T`:

```cpp
zimat::matrix<int> a(2, 2);
a(1, 1) = 1; a(1, 2) = 2;
a(2, 1) = 3; a(2, 2) = 4;
int determinant = a.det(); // -2
```

В текущей реализации формулы реализованы только для квадратных матриц размеров `1 × 1`, `2 × 2` и `3 × 3`. Для всех остальных размеров, в том числе неквадратных, возвращается `-1`. Это значение не позволяет отличить неподдерживаемый размер от настоящего определителя `-1`.

Для типа `T` используется обычная арифметика этого типа. Для целых типов возможны переполнение и ограничения диапазона.

## Хранение данных

Матрица хранит элементы в непрерывном `std::vector<T>` в порядке строк (row-major). Для элемента с нулевыми внутренними координатами `(r, c)` формула линейного индекса:

```text
index = r * число_столбцов + c
```

Например:

```text
1 2 3       [1, 2, 3, 4, 5, 6]
4 5 6   ->
```

Пользовательская база индексов применяется при обращении через `operator()`, но не меняет физический порядок хранения.

## Ограничения текущей версии

- `operator()` не проверяет индексы на выход за границы.
- Арифметические операторы не обеспечивают обработку несовместимых размеров.
- `det()` ограничен размерами `1 × 1`, `2 × 2` и `3 × 3`; на остальных возвращает `-1`.
- `operator/` не проверяет делитель на ноль.
- При арифметике используются возможности и ограничения типа `T` (например, целочисленное деление и переполнение).
