## Подключение

ZiMatLib — header-only библиотека на C++17. Подключите каталог `include` и заголовок:

```cpp
#include <zimat/zimat.hpp>
```

При использовании CMake добавьте репозиторий и свяжите цель `zimat`:

```cmake
add_subdirectory(path/to/ZiMatLib)
target_link_libraries(my_app PRIVATE zimat)
```

Цель `zimat` имеет тип `INTERFACE` и передаёт путь к заголовкам и требование C++17.

## Класс `zimat::matrix<T>`

```cpp
template<typename T>
class zimat::matrix;
```

`T` — тип элементов. Для используемых операций тип должен поддерживать нужные арифметические операции и присваивание их результатов. Для методов сравнения дополнительно требуется соответствующее сравнение элементов.

[↑ К оглавлению](#навигация)

## Создание и индексация

```cpp
zimat::matrix<int> a;          // 0 × 0, база индексации 1
zimat::matrix<double> b(3, 4); // 3 × 4, база 1
zimat::matrix<int> c(2, 2, 0); // 2 × 2, база 0
```

Конструктор размера имеет сигнатуру `matrix(size_t rows, size_t cols, size_t base_numeric = 1)`. Элементы создаются со значениями по умолчанию для `T`. Память выделяется под `rows * cols` элементов.

`operator()(row, column)` возвращает ссылку на элемент; const-вариант возвращает константную ссылку:

```cpp
a(1, 2) = 7;
int value = a(1, 2);
```

Индексы передаются с учётом текущей базы. Оператор не проверяет выход за границы.

## Изменение матрицы

### `resize(rows, cols, base_numeric = 1)`

Меняет размеры, внутренний вектор и базу индексации. Существующие элементы сохраняются в пределах нового размера согласно поведению `std::vector::resize`, новые элементы получают значение по умолчанию. Если третий аргумент не передан, база становится равна `1`.

### `fill(value)`

Заполняет все элементы значением и возвращает `matrix&`, поэтому вызовы можно объединять:

```cpp
a.fill(0).fill(1);
```

Размеры и база индексации не меняются.

## Размеры и данные

Следующие пары методов возвращают одно и то же:

| Методы | Результат |
|---|---|
| `rows()`, `get_rows()` | Число строк (`size_t`) |
| `cols()`, `get_cols()` | Число столбцов (`size_t`) |
| `base_numeric()`, `get_base_numeric()` | База индексации (`size_t`) |
| `data()`, `get_data()` | Константная ссылка на `std::vector<T>` |

`size()` возвращает число элементов (`rows * cols`). `get_row(row)` и `get_col(col)` возвращают копии соответствующей строки или столбца в виде `std::vector<T>`. Для этих методов индекс строки или столбца также задаётся с учётом базы.

`set_base_numeric(value)` меняет только базу адресации, не перемещая элементы и не меняя размеры.

## Проверки

- `empty()` возвращает `true`, если число строк **или** столбцов равно нулю.
- `is_empty()` — синоним `empty()`.
- `is_zeros()` возвращает `true`, если каждый элемент сравнивается равным `0`. Для пустого вектора возвращает `true`.
- `is_square()` возвращает `true`, если число строк равно числу столбцов; матрица `0 × 0` также считается квадратной.

## Арифметика и транспонирование

Операторы возвращают новые матрицы. Сложение и вычитание выполняются поэлементно; умножение двух матриц — стандартное матричное умножение; умножение и деление на `T` применяются к каждому элементу.

| Выражение | Условие |
|---|---|
| `a + b`, `a - b` | Размеры матриц должны совпадать |
| `a * b` | `a.cols() == b.rows()` |
| `a * scalar`, `a / scalar` | `scalar` имеет тип `T` |

Результат сохраняет базу индексации левого операнда. Умножение матриц возвращает размер `a.rows() × b.cols()`.

`t()` и `transpose()` возвращают транспонированную копию; `transpose()` вызывает `t()`. База индексации сохраняется.

```cpp
zimat::matrix<int> a(2, 3);
auto b = a.transpose(); // 3 × 2
```

Обратите внимание: в текущей реализации ветки несовместимости размеров в `operator+`, `operator-` и `operator*` не выбрасывают исключение и не возвращают матрицу. Использовать операции с несовместимыми размерами нельзя. Деление на ноль отдельно не проверяется.

## Статистика

- `sum()` возвращает сумму элементов.
- `sum(const matrix&)` возвращает сумму элементов переданной матрицы; объект, на котором вызван метод, не участвует в расчёте.
- `max()` и `min()` возвращают наибольший и наименьший элемент.
- `max(const matrix&)` и `min(const matrix&)` вычисляют максимум или минимум переданной матрицы.
- `max_in_row(row)` и `min_in_row(row)` возвращают экстремум строки.
- `max_in_col(col)` и `min_in_col(col)` возвращают экстремум столбца.

Для поиска по строке и столбцу используется пользовательская база индексации. Методы `max`, `min` и поиска в строке/столбце не определяют результата для пустых данных; вызывайте их только для непустой матрицы и существующей строки или столбца. Тип `T` должен поддерживать сравнение для поиска минимума и максимума.

## Определитель и исключения

`det()` возвращает определитель типа `T` для квадратных матриц `1 × 1`, `2 × 2` и `3 × 3`. Для любого другого размера, включая неквадратные матрицы, выбрасывается `std::runtime_error` с сообщением `Unsupported matrix size`.

```cpp
zimat::matrix<int> a(2, 2);
a(1, 1) = 1; a(1, 2) = 2;
a(2, 1) = 3; a(2, 2) = 4;
int determinant = a.det(); // -2
```

В коде библиотеки это единственное реализованное явное исключение. Остальные описанные ограничения (например, несовместимость размеров) не обрабатываются исключениями.

## Хранение и ограничения

Элементы находятся в непрерывном `std::vector<T>` в порядке строк. Для внутренних координат строки `r` и столбца `c`, начинающихся с нуля:

```text
index = r * число_столбцов + c
```

При обращении через `operator()` внутренние координаты получаются вычитанием `base_numeric` из переданных индексов. База меняет адресацию, но не физический порядок хранения.

Текущие ограничения реализации:

- Нет проверки индексов в `operator()`, `get_row` и `get_col`.
- Несовместимые размеры арифметических операций не обрабатываются корректно.
- `det()` поддерживает только порядки 1–3 и сигнализирует об остальных через `std::runtime_error`.
- Деление на ноль не проверяется; целочисленный `T` использует целочисленное деление.
- Переполнение при вычислениях зависит от типа `T`.
