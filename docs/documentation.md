## Подключение и требования

ZiMatLib — header-only библиотека на C++17. Отдельная сборка библиотеки не требуется. Подключите каталог `include` к путям поиска заголовков проекта и включите зонтичный заголовок:

```cpp
#include <zimat/zimat.hpp>
```

Он подключает класс матрицы, арифметические операции, транспонирование, проверки состояния, статистику, определитель и объявленный метод следа.

При подключении репозитория через CMake:

```cmake
add_subdirectory(path/to/ZiMatLib)
target_link_libraries(my_app PRIVATE zimat)
```

Цель `zimat` имеет тип `INTERFACE` и передаёт пути к заголовкам и требование C++17.

## Быстрый старт

```cpp
#include <zimat/zimat.hpp>
#include <iostream>

int main() {
    zimat::matrix<int> a(2, 2);
    zimat::matrix<int> b(2, 2);

    a(1, 1) = 1; a(1, 2) = 2;
    a(2, 1) = 3; a(2, 2) = 4;
    b.fill(1);

    auto sum = a + b;
    auto transposed = a.transpose();

    std::cout << sum(1, 1) << '\n';       // 2
    std::cout << transposed(1, 2) << '\n'; // 3
    std::cout << a.sum() << '\n';         // 10
    std::cout << a.det() << '\n';         // -2
}
```

По умолчанию строки и столбцы адресуются индексами от `1`. Чтобы использовать индексы от `0`, передайте `0` третьим аргументом конструктора: `zimat::matrix<int> a(2, 2, 0);`.

## Класс `zimat::matrix`

```cpp
template<typename T>
class zimat::matrix;
```

`T` задаёт тип элементов. Класс хранит размеры, базовый индекс и элементы в `std::vector<T>`. Для сложения, вычитания, умножения и деления `T` должен поддерживать соответствующие операции и присваивание результата. Методы поиска экстремумов дополнительно требуют сравнения элементов; `is_zeros()` требует сравнения с `0`.

Публичный интерфейс сгруппирован ниже по задачам: создание и доступ, изменение, чтение размеров и содержимого, проверки, арифметика и анализ элементов.

[↑ К оглавлению](#навигация)

### Создание матрицы

#### Пустая матрица

```cpp
zimat::matrix<double> empty;
```

Создаётся матрица размером `0 × 0` с базовым индексом `1`.

#### Матрица заданного размера

```cpp
zimat::matrix<double> values(3, 4);
zimat::matrix<int> zero_based(2, 2, 0);
```

Первые два аргумента — число строк и столбцов, третий — начальный индекс адресации строк и столбцов. Если базовый индекс не задан, используется `1`. Элементы создаются со значениями по умолчанию для `T` (для встроенных арифметических типов это нулевые значения).

Размеры хранятся в `size_t`; отдельной проверки переполнения произведения `rows * cols` конструктор не выполняет.

[↑ К оглавлению](#навигация)

### Индексация и доступ к элементам

Оператор `operator()(row, column)` возвращает ссылку на элемент и поэтому подходит как для чтения, так и для записи. Для константной матрицы возвращается константная ссылка:

```cpp
zimat::matrix<int> a(2, 2);
a(1, 2) = 7;
int value = a(1, 2);

const auto& read_only = a;
int same_value = read_only(1, 2);
```

Передаваемые координаты учитывают `base_numeric()`: при базе `1` первая ячейка — `(1, 1)`, при базе `0` — `(0, 0)`. Метод не проверяет диапазон координат. Неверный индекс может привести к обращению вне `std::vector` и неопределённому поведению.

[↑ К оглавлению](#навигация)

### Изменение размера и заполнение

#### `resize(rows, cols, base_numeric = 1)`

Меняет размеры и базовый индекс матрицы:

```cpp
a.resize(3, 4);       // 3 × 4, база индексации 1
a.resize(2, 2, 0);    // 2 × 2, база индексации 0
```

Как и `std::vector::resize`, операция сохраняет начальную часть прежнего линейного вектора, если новый размер меньше или равен старому, и добавляет элементы со значением по умолчанию при увеличении. Это сохранение относится к линейному массиву: изменение числа столбцов может поменять координаты, которым соответствуют сохранённые элементы. Если третий аргумент не передан, база сбрасывается на `1`.

#### `fill(value)`

Присваивает `value` каждому существующему элементу и возвращает ссылку на текущую матрицу (`matrix&`):

```cpp
a.fill(0);
a.fill(1).fill(2); // цепочка допустима; после неё все элементы равны 2
```

Размеры и базовый индекс не меняются. Для матрицы без элементов метод ничего не меняет.

[↑ К оглавлению](#навигация)

### Получение размеров и данных

Методы `rows()` и `get_rows()` возвращают число строк типа `size_t`. `cols()` и `get_cols()` возвращают число столбцов того же типа. Это две пары эквивалентных имён:

```cpp
auto row_count = a.rows();
auto column_count = a.cols();

auto same_row_count = a.get_rows();
auto same_column_count = a.get_cols();
```

`size()` возвращает число элементов, равное `rows() * cols()`.

Методы `data()` и `get_data()` возвращают константную ссылку на внутренний `std::vector<T>`:

```cpp
const std::vector<int>& elements = a.data();
```

Через эти методы изменить элементы вектора нельзя. Элементы перечислены в порядке строк (row-major): сначала все столбцы первой строки, затем второй и так далее.

[↑ К оглавлению](#навигация)

### Получение строки или столбца

`get_row(row)` и `get_col(col)` возвращают копию выбранной строки или столбца как `std::vector<T>`:

```cpp
std::vector<int> row = a.get_row(1);
std::vector<int> column = a.get_col(2);
```

Индекс строки или столбца задаётся с учётом текущей базы. Строка содержит `cols()` элементов, столбец — `rows()` элементов. Возвращаются копии, поэтому изменение полученного вектора не меняет матрицу. Проверки существования строки, столбца и допустимости индекса нет; неверный индекс может вызвать неопределённое поведение.

[↑ К оглавлению](#навигация)

### Базовый индекс

`base_numeric()` и `get_base_numeric()` возвращают текущую базу адресации типа `size_t`. `set_base_numeric(value)` меняет её:

```cpp
a.set_base_numeric(0);
auto first_index = a.base_numeric();
```

Изменяется интерпретация координат в `operator()`, `get_row()` и `get_col()`. Размеры и линейное расположение данных остаются прежними. После изменения базы для доступа к тем же ячейкам используйте координаты с новой базой.

[↑ К оглавлению](#навигация)

## Проверки состояния матрицы

### `empty()` и `is_empty()`

`empty()` возвращает `true`, если число строк **или** число столбцов равно нулю. `is_empty()` — синоним `empty()`:

```cpp
if (a.empty()) {
    // Матрица не содержит ячеек хотя бы по одному измерению.
}
```

Таким образом, матрицы `0 × 0`, `0 × 3` и `4 × 0` считаются пустыми.

### `is_zeros()` и `zeroqxq()`

`is_zeros()` проверяет, сравнивается ли каждый элемент с нулём. `zeroqxq()` вызывает `is_zeros()` и возвращает тот же результат; это дополнительное имя метода:

```cpp
bool all_zero = a.is_zeros();
bool same_result = a.zeroqxq();
```

Для матрицы без элементов `is_zeros()` возвращает `true`, поскольку ни одного ненулевого элемента не найдено. Элементы `T` должны поддерживать сравнение `!= 0`.

### `is_square()`

Возвращает `true`, если число строк совпадает с числом столбцов. Матрица `0 × 0` также считается квадратной.

## Арифметические операции

Все арифметические операторы создают новую матрицу; операнды не изменяются. Результат наследует базовый индекс левого операнда.

| Выражение | Смысл | Требуемые размеры |
|---|---|---|
| `a + b` | Поэлементное сложение | одинаковые строки и столбцы |
| `a - b` | Поэлементное вычитание | одинаковые строки и столбцы |
| `a * b` | Стандартное матричное умножение | `a.cols() == b.rows()` |
| `a * scalar` | Умножение каждого элемента на скаляр | скаляр имеет тип `T` |
| `a / scalar` | Деление каждого элемента на скаляр | скаляр имеет тип `T` |

Пример:

```cpp
auto sum = a + b;
auto difference = a - b;
auto product = a * b;
auto scaled = a * 2;
auto halved = a / 2;
```

Сложение и вычитание сохраняют размер операндов. Матричное умножение возвращает матрицу размера `a.rows() × b.cols()`. Умножение и деление на скаляр сохраняют размер исходной матрицы.

В текущей реализации ветви для несовместимых размеров в `operator+`, `operator-` и матричном `operator*` пустые: исключение не выбрасывается, а корректный результат не возвращается. Такие операции использовать нельзя. Деление на ноль отдельно не проверяется. Для целочисленного `T` выполняется целочисленное деление, а переполнение зависит от типа.

## Транспонирование

`t()` и `transpose()` создают новую матрицу, меняя местами строки и столбцы. `transpose()` вызывает `t()` и служит более описательным именем:

```cpp
zimat::matrix<int> a(2, 3);
a(1, 1) = 1; a(1, 2) = 2; a(1, 3) = 3;
a(2, 1) = 4; a(2, 2) = 5; a(2, 3) = 6;

auto b = a.transpose(); // размер 3 × 2
// b содержит:
// 1 4
// 2 5
// 3 6
```

Базовый индекс результата совпадает с базовым индексом исходной матрицы. Исходная матрица не изменяется.

## Статистические методы

### Сумма элементов: `sum()`

`sum()` возвращает сумму всех элементов типа `T`. Начальное значение аккумулятора — `T{}`:

```cpp
int total = a.sum();
```

Для пустой матрицы возвращается `T{}`. Результат ограничен арифметикой и диапазоном типа `T`.

Перегрузка `sum(const matrix&)` вычисляет сумму переданной матрицы. Матрица, на которой вызван метод, в расчёте не участвует:

```cpp
int total = a.sum(b); // сумма элементов b
```

### Максимум и минимум: `max()` и `min()`

`max()` возвращает наибольший элемент текущей матрицы, а `min()` — наименьший. Перегрузки `max(const matrix&)` и `min(const matrix&)` вычисляют экстремум переданного объекта; вызывающая матрица не используется.

```cpp
int largest = a.max();
int smallest = a.min();
int largest_in_b = a.max(b);
int smallest_in_b = a.min(b);
```

Матрица должна содержать хотя бы один элемент. Для пустых данных реализации `max()` и `min()` доходят до конца функции без возвращаемого значения, что приводит к неопределённому поведению. Тип `T` должен поддерживать сравнение `<`.

### Экстремумы строки и столбца

`max_in_row(row)` и `min_in_row(row)` ищут соответственно максимум и минимум выбранной строки. `max_in_col(col)` и `min_in_col(col)` выполняют поиск в столбце:

```cpp
int row_max = a.max_in_row(1);
int row_min = a.min_in_row(1);
int column_max = a.max_in_col(2);
int column_min = a.min_in_col(2);
```

Индексы строки и столбца задаются с учётом `base_numeric()`. Требуется непустая выбранная строка или столбец и корректный индекс. Эти условия не проверяются: при пустой матрице метод не возвращает значение, а неверный индекс может вызвать неопределённое поведение.

## След матрицы

Метод `trace()` объявлен в классе и включён в зонтичный заголовок, но его текущая реализация в `include/zimat/linalg/trace.hpp` не завершена: тело не вычисляет сумму диагонали и не возвращает значение. Поэтому метод нельзя считать рабочим и использовать в программе до завершения реализации.

Для обычного следа матрица должна быть квадратной, а результатом должна быть сумма элементов главной диагонали. Эти ожидаемые правила описывают назначение операции, но текущий код их не выполняет и не проверяет.

## Определитель

`det()` возвращает определитель типа `T` для квадратных матриц размеров `1 × 1`, `2 × 2` и `3 × 3`:

```cpp
zimat::matrix<int> a(2, 2);
a(1, 1) = 1; a(1, 2) = 2;
a(2, 1) = 3; a(2, 2) = 4;
int determinant = a.det(); // -2
```

Для размеров `1 × 1`, `2 × 2` и `3 × 3` используются прямые формулы. Для любого другого размера, включая неквадратные матрицы, выбрасывается `std::runtime_error` с сообщением `Unsupported matrix size`:

```cpp
try {
    auto value = a.det();
} catch (const std::runtime_error& error) {
    // Размер матрицы не поддерживается.
}
```

Целочисленный тип может переполниться при вычислении; точность и диапазон определяются `T`.

## Хранение данных и индексация

Элементы лежат в непрерывном `std::vector<T>` в порядке строк (row-major). Например, матрица

```text
1 2 3
4 5 6
```

представлена последовательностью `[1, 2, 3, 4, 5, 6]`. Для внутренних координат, начинающихся с нуля, линейный индекс вычисляется так:

```text
index = row * cols + column
```

База применяется только при преобразовании координат, переданных пользователем. Общая формула:

```text
index = (row - base_numeric) * cols + (column - base_numeric)
```

В частности:

- при `set_base_numeric(0)`: `index = row * cols + column`;
- при `set_base_numeric(1)`: `index = (row - 1) * cols + (column - 1)`.

Изменение базы не переставляет элементы. Например, для матрицы с `cols == 3` координаты `(1, 2)` при базе `1` указывают на индекс `(1 - 1) * 3 + (2 - 1) = 1`, то есть на второй элемент линейного вектора.

## Ограничения текущей версии

- `operator()`, `get_row()` и `get_col()` не проверяют границы индексов.
- Конструктор и `resize()` отдельно не проверяют переполнение произведения размеров.
- Для несовместимых размеров арифметические операторы не выбрасывают исключение и не возвращают корректный результат.
- `max()`, `min()` и поиск экстремумов не имеют определённого результата для пустых данных; строки и столбцы также не проверяются на существование.
- `trace()` пока объявлен, но не реализован.
- `det()` поддерживает только квадратные размеры `1 × 1`, `2 × 2` и `3 × 3`; остальные вызывают `std::runtime_error`.
- Деление на ноль не проверяется; для целочисленного `T` применяется целочисленное деление.
- Переполнение при арифметике и суммировании зависит от типа `T`.
